SUCCESS CORNER EDUCATION WEBSITE

Files:
- index.html = Home
- course.html = Course
- timetable.html = Timetable
- contact.html = Contact
- assets/style.css = design
- assets/script.js = mobile menu + contact form demo
- assets/images = your uploaded school photos

HOW TO USE
1. Open index.html in Chrome to preview.
2. Edit the placeholder phone, email, address, course names, fees, and timetable in the HTML files.
3. Upload the whole folder to Netlify, GitHub Pages, Cloudflare Pages, cPanel/public_html, or another static host.
4. The contact form currently shows a success message only. To receive real messages, connect it to Formspree, Netlify Forms, or a backend/email service.

This website is responsive and works on desktop and mobile.
